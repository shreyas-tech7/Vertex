## ti84-redesign (R1)

- [R1] Branch — work is on `ti84-redesign` as the task asked, pushed to `origin/ti84-redesign` and mirrored to the session branch `claude/compassionate-hawking-app7ba`. Nothing goes to `main`. The M0 rule about the session branch no longer applies to this work.
- [R1] Engine pivot — the calculator now runs CEmu (GPLv3, WebAssembly) with the visitor's own ROM. The from-scratch engine in `docs/SPEC.md` is not built. `src/core` keeps `brand.ts` and the key table only (reason: the task replaces the calculator with a real emulator).
- [R1] Reference site not reachable — `ti84calculator.io` and `ce-programming.github.io` return 403 from this sandbox's egress policy, so they were not fetched and nothing was routed around the block. The landing page follows the reference repo's `index.html` and `ti84calc.html` (MIT). The language menu, the independent-site notice and the privacy and terms links come from the task text and its fallback tokens, so they are not measured against the live site.
- [R1] Reference comparison — `scripts/compare-reference.mjs` renders the reference repo's `index.html` locally with its iframe replaced by a blank page (the real iframe page would call TI and Pearson hosts) and compares computed styles of 27 element pairs with Vertex at 1440x900 and 390x844.
- [R1] Calculator box — 340 x 738 px at 100% zoom. The reference's box was not measurable (its emulator and faceplate come from hosts Vertex never contacts, and the live site was blocked). 340 px lets the 320 x 240 LCD show at exactly 1:1, so nearest-neighbour scaling is pixel-exact at 100%. One place to change it: `BODY_WIDTH` and `BODY_HEIGHT` in `src/calculator/keypadLayout.ts` plus `.calc-body` in `calculator.css`.
- [R1] Frameworks — kept Vite, React, TypeScript, Vitest, Playwright and the PWA plugin. Removed Tailwind (all design is hand-written CSS copied from the reference) and decimal.js (CEmu does the math). The landing, privacy and terms pages are plain generated HTML with no React. Only the calculator page uses React.
- [R1] Generated pages are committed — `node scripts/generate-pages.ts` writes 27 HTML files, `public/_headers`, `vercel.json`, `robots.txt` and `sitemap.xml` from `src/site`. The Vite config runs it on every start and a unit test checks the files are current.
- [R1] URLs — English at `/`, other languages at `/fr/` and so on, policies at `/privacy/` and `/terms/` (and `/fr/privacy/`). Directory URLs work on any static host. The standalone calculator page is `calculator.html?lang=xx`.
- [R1] Language menu — a `details` element with plain links, so it works without JavaScript and every link can be checked. Each language names itself.
- [R1] Contact line — omitted. Vertex has no contact address in the repository. Privacy and terms point to GitHub issues instead.
- [R1] Copyright line — "© 2026 Vertex." without "All rights reserved", because the code is MIT licensed and the emulator is GPLv3.
- [R1] Feature card replaced — "Exam Compatible" became "Real TI-OS" (same emoji). The standardized-test claim is gone from all nine languages. The terms say Vertex is not an approved exam calculator.
- [R1] Other reference lines rewritten — "Matrix operations (up to 10x10)" (not true of TI-OS), "Perfect For > Students" (needs a ROM, not hardware-free), "Internet connection (required for initial loading)" became "for the first load".
- [R1] Copy rules — no em dashes, en dashes, semicolons or spaced hyphens in any language, no filler words. `src/site/i18n/copy.test.ts` enforces this. Russian uses "является" where it would normally use a dash.
- [R1] Translations — written by the agent, not by a human translator. Native review is advised. Key legends stay as printed on the keys.
- [R1] ROM validation — CEmu's own `emu_load` runs it, in a second WebAssembly instance, because loading a ROM tears down the running calculator. A bad replacement therefore leaves the old calculator untouched. A ROM that CEmu loads but cannot identify as a CE (state `NOT_A_CE`) is refused.
- [R1] Saved state — written to IndexedDB when the tab hides, on `pagehide`, and every 30 s while the user has pressed keys. A state belongs to a ROM size and is dropped when the ROM changes or is removed. It is about 5 MB.
- [R1] Pausing — the worker stops stepping and lifts all keys when the tab hides. It resumes when the tab shows again, without catching up.
- [R1] Pacing — 60 frames per emulated second (CEmu `emu_run(1)` at its 60 Hz run clock, 800,000 cycles of the 48 MHz CPU). The worker never catches up more than three frames at a time.
- [R1] Frames — the worker posts RGBA frames to the page, which paints with `putImageData`. OffscreenCanvas was not used, so tests can read the canvas, and so older Safari works. Unchanged frames are not posted.
- [R1] Key hold — a key stays down at least 3 frames and up at least 2 before the next press, so quick clicks and key strokes register in TI-OS. A held key is never delayed.
- [R1] Keyboard — follows the ti84ce README. Shift and Alt press 2nd and ALPHA when tapped alone, so Shift+9 still types "(". Space presses 0, as in CEmu (the README uses it to pause, and Vertex has no pause). Gaps in the README table are filled with `d` for MODE and `q` for x². `V` sends 2nd then x².
- [R1] Dropped files — any `.8x?`-style TI variable or app file is sent. `.8eu` OS files are refused. A `.rom` file, or an unknown file of 1 MB or more, is treated as a ROM and replaces the current one after CEmu validates it.
- [R1] Adapter — `emulator/src/vertex_adapter.c` replaces CEmu's own Emscripten front end. It `#include`s CEmu's `keypad.c` (left out of the compile list) to read the file-static key matrix, so CEmu stays unmodified.
- [R1] CEmu pin — commit `54f4a9a4eb9e1c89a7c405705b1a1fc1ab428da2`, Emscripten 4.0.10, `-O3 -flto -DNDEBUG` (release build, so CEmu's debug asserts cannot abort the WebAssembly), a 512 KB stack, no threads (so no COOP and COEP headers are needed), `-sDYNAMIC_EXECUTION=0` (no eval in the glue).
- [R1] Build output committed — `emulator/dist/*` is committed so GitHub Pages, Vercel and CI can build the site with Node alone. `emulator/build.sh` rebuilds it and the source archive.
- [R1] Source archive — `public/source/vertex-emulator-source.tar.gz` holds the full CEmu tree at the pinned commit (`CEmu/`) and `emulator/` (adapter, build script, both licenses) in the repository's own layout. It is deterministic, and unpacking it and running `emulator/build.sh` rebuilds a byte-identical `vertex-cemu.wasm` (checked).
- [R1] CSP — a meta tag in every built page, and the same policy plus `frame-ancestors` in `public/_headers` and `vercel.json`. The preview server sends the headers, so the tests run under the full policy. The dev server sends none, because Vite and React Refresh need inline scripts.
- [R1] Service worker — registered by `src/site/serviceWorker.ts` using its own script URL, so one build works from every folder. `vite-plugin-pwa` links the manifest as `./manifest.webmanifest`, so `closeBundle` rewrites it per folder.
- [R1] Test ROM — `src/test-support/syntheticRom.ts` builds 4 MiB of 0xFF with just the certificate fields CEmu checks. It runs no code and is never written to disk. It lets the tests cover ROM acceptance, boot, keys and state save and restore without a real ROM.
